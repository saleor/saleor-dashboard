Order details now open in a *Line matrix* view so you can work order line by order line. See fulfillment and refund progress for every item in one place, open a line's shipments when you need to, and start a return or refund from that same context. *Needs action* keeps focus on lines that still need approval or refund follow-up. Refund issues are easier to spot and resolve, with the same refund flow whether you start from the matrix, a fulfillment, or elsewhere on the order.

*Timeline* is still there for a shipment-by-shipment view.
