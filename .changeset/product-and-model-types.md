Product and model types now match the rest of the dashboard. Create opens a short dialog (name and kind), then you finish attributes, shipping, and tax on the type page. You can create a type from the product or model list without leaving — including a dropdown next to Create product / Create model.

Type details show how attributes appear on the product page, and creating an attribute accepts a pasted list of values. Model types use the same attribute list as product types (including required values).
