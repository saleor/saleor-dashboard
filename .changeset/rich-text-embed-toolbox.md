The rich text editor now has an "Embed" item in its "+" menu. It asks for a link and embeds a YouTube or Vimeo video, a post, or another supported page. Before, an embed could only be added by pasting a link into an empty line, which was hard to find. If the link can't be embedded, the editor now shows an error. An embed block with no link isn't saved.
