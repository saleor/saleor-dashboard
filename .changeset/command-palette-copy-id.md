Cmd+K now has "Copy … ID" actions for the page you are on. On orders and draft orders, you can also copy the order number. On a product variant, you can copy both the variant ID and its product ID. Other detail pages (customers, collections, categories, gift cards, vouchers, discounts, models, model types, structures, channels) get a "Copy … ID" action too. The copied value is the GraphQL ID used by the API, and a toast confirms the copy.
